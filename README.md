## 🚀 Featured Project

### Blast-Radius Guard

**Safe configuration delivery for distributed Kubernetes systems.**

A production-style DevOps/SRE project that validates configuration, verifies integrity and signatures, progressively promotes changes across Kubernetes cells, monitors health, and automatically halts and rolls back unsafe releases.

**Validation → Signing → Staged Rollout → Health Gate → Automatic Rollback**

**Engineering highlights**
- 🔐 SHA-256 integrity verification
- ✍️ Ed25519 configuration signing
- ☁️ Versioned S3 configuration artifacts
- ☸️ Kubernetes multi-cell rollout simulation
- 📈 Prometheus observability
- 🛑 Health-gated promotion and automatic rollback
- 💾 Durable rollout-state recovery
- 🧪 28 automated tests
- ⚙️ GitHub Actions CI/CD
- 🏗️ Terraform infrastructure
